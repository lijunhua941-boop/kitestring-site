从哪里开始？要付费吗？

  • 最省事：在要连接的 Mac 上打开 Claude Code 或 Codex，把下载页上的那句话发给它。它负责下载、安装和检查，需要你动手时会告诉你。
  • 自己装：在「终端」里运行 curl -fsSL https://lijunhua941-boop.github.io/kitestring-site/install.sh | bash，或从下载页下载 DMG，然后按 App 的「设置向导」逐步完成。
  • 费用：Kitestring for Mac 免费；iPhone App 的演示模式免费。连接你自己的 Mac 需要 Kitestring Pro（按年订阅或一次买断，没有试用期，价格在 App 里显示）。建议先把 Mac 这边装好、「设置向导」前几步都打勾，再在 iPhone 上购买和扫码。
  • 下载很慢或总是中断：用上面的命令，它会分段下载并断点续传；中断了重新运行同一条命令即可。

装机卡在某一步怎么办？

Kitestring for Mac 的「设置向导」共六步（菜单栏「设置向导…」随时可再打开）。App 自动检查每一步，完成后标记为已完成。卡住时按对应的一步处理：

  1. Tailscale：没检测到就从 Tailscale 官网安装并登录；iPhone 也要装，并登录同一个账号。
  2. 远程登录：设置向导会打开系统设置的共享页面，打开「远程登录」即可，见下文。
  3. 安装助手：只写入你的用户目录，不需要管理员密码，设置向导会列出每一步做了什么。失败时把「诊断」结果发给我们。
  4. Claude Code / Codex：要用编程助手会话就至少装一个（只用终端会话可以跳过，见下文），按它们官方的安装说明操作；登录可以以后在 iPhone 上发起，登录过程在 Mac 上执行。
  5. 授权常用文件夹：macOS 会询问 App 能否访问「文稿」「桌面」「下载」，点「允许」。见文件夹授权。
  6. 配对 iPhone：见配对失败。

Tailscale 要怎么设置？

  • Mac 与 iPhone 登录同一个 Tailscale 账号，在两边的 Tailscale App 里确认是同一个网络（tailnet），设备都显示已连接、未过期。
  • Mac 上的 Tailscale 要允许入站连接：不要开启「阻止传入连接」（Block incoming connections / Shields Up）。
  • 如果你的 tailnet 用了访问控制（ACL / Grants），要允许 iPhone 访问 Mac 的 TCP 22 端口。
  • 不需要开启 Tailscale SSH。两端用不同的出口节点（Exit Node）也没问题。

远程登录要怎么打开？

系统设置 › 通用 › 共享 › 远程登录：打开；「允许访问」选「仅这些用户」，只保留运行 Claude Code / Codex 的账户。

Kitestring 不修改 sshd 的全局配置，不开 root 登录，也不关闭密码登录。配对时生成的密钥只接受来自 Tailscale 地址的登录，并且只能进入受管会话。

配对失败怎么办？

  • iPhone App 要求 Kitestring Pro：连接自己的 Mac 需要先购买或恢复购买。买完后二维码可能已经过期，回到 Mac 重新点「配对 iPhone」拿一个新的再扫。
  • Mac 提示「另一个配对正在进行」：同一时间只能有一个配对码。扫已经打开的那个二维码（可能在「预览」或终端窗口里），或者先把它关掉（终端里按 Control-C），再点「配对 iPhone」。
  • Kite Voice 提示「这不是 Kitestring 的配对二维码」：这是 Kite Voice 1.0.0 的问题，在 App Store 更新到 1.0.1 或更高版本后再扫。
  • 二维码 10 分钟内有效、只能用一次。过期或已用过，就在 Mac 菜单栏重新点「配对 iPhone」。
  • 配对链接里的 Mac 地址必须是 Tailscale 地址；iPhone 上的 Tailscale 没连接时会连不上，先在 iPhone 上打开 Tailscale。
  • 从 App 以外打开的配对链接，App 会先显示 Mac 名称、地址与用户名，你确认后才配对。
  • App 提示「主机身份已改变」时不要随意信任：可能是有人冒充，也可能是 Mac 重装或换了主机密钥。确认是自己的 Mac 后，在 App 设置里点「重新验证主机身份」，或重新配对。
  • App 顶部的提示会分层说明问题出在哪：iPhone 的 Tailscale、Mac 睡眠或离线、远程登录没开、助手不存在、会话服务没运行。点「详情」可以看原始错误。

手机上的会话卡在启动画面，Mac 上弹出「想要访问文稿/桌面」？

会话服务所在的环境还没有这个文件夹的访问授权，macOS 正在等你回答。在 Mac 上点「允许」即可。如果之前点了「不允许」：打开系统设置 › 隐私与安全性 › 文件与文件夹，打开对应文件夹的开关，然后在菜单栏先点「停止服务」再点「启动服务」。菜单栏的「诊断」会显示哪个文件夹被阻塞。

为什么 Claude Code 显示我没有登录？

如果你在 Mac 上已经登录，会话里的 Claude Code 却显示未登录：会话服务必须在你登录 Mac 的图形界面环境里启动，才能读取登录钥匙串里保存的登录凭证；从 SSH 启动的服务读不到。关闭全部会话后，在 Mac 菜单栏先点「停止服务」再点「启动服务」。我们不读取、不复制你的登录凭证，也不会替你解锁钥匙串。

Mac 需要一直开着吗？

Mac 需要保持通电、联网和唤醒，并登录你的账户。屏幕可以锁定或关闭显示器，但系统睡眠后就连不上了；Kitestring 不修改你的电源设置，请在系统设置的电池/节能里自行确认。Mac 重启或注销后，原来的会话进程不会继续存在。

App 里显示「还没有会话」？

说明 iPhone 已经连上 Mac，只是 Mac 上还没有受管会话。点会话列表下方的「新建会话」，选 Claude Code、Codex 或终端：默认在 Mac 的主目录启动，也可以选最近用过的目录。在 Mac 上用 Kitestring 建的会话也会出现在列表里。Mac 菜单栏「会话」一栏里的「没有会话」也是同样的意思。

Mac 菜单栏显示「没有已配对的设备」？

这台 Mac 还没有配对任何 iPhone，或者配对过的 iPhone 都已撤销。在菜单栏点「配对 iPhone…」，用 iPhone App 扫码即可（见配对失败）。iPhone 上原来的配对若已被撤销，App 就连不上这台 Mac，重新扫码配对即可。

Mac 上没装 Claude Code 或 Codex？

不装也能用：在 iPhone 上新建「终端」会话就是 Mac 上的普通 shell。要用编程助手会话，按 Claude Code 或 Codex 官方说明在这台 Mac 上安装其中一个（设置向导第 4 步会检测并给出链接），装好后再在 iPhone 上新建对应的会话；没装就新建，App 会提示这台 Mac 上找不到该程序。

手机丢了怎么办？

在 Mac 菜单栏「已配对设备」里撤销这部 iPhone。建议平时开启 App 的 Face ID 或设备密码锁：会话里的 Claude Code 与 Codex 以你的 macOS 账户权限运行，拿到解锁的 iPhone 和 App 的人就能向它们下指令。

如何卸载？

  1. 在 Mac 菜单栏选「卸载」。仍有运行中的会话时会先列出来，请你确认。
  2. 卸载会撤销全部 iPhone 密钥（修改 authorized_keys 前先备份）、删除登录项与安装的文件；会话状态目录会保留，以便重装后恢复。不会删除 Claude Code / Codex 的凭证、你的项目代码或你自己的其他 tmux 会话。
  3. 把 Kitestring for Mac 拖进废纸篓。
  4. 在 iPhone 上删除 App。Tailscale 和远程登录保持你自己的设置，安装时没有改动它们。

如何反馈问题？

  • iPhone App：设置 › 反馈与诊断。反馈默认发到你自己的 Mac，在 Mac 菜单栏「收件箱与反馈」里查看。

Where Do I Start, and What Does It Cost?

  • Easiest: on the Mac you want to reach, open Claude Code or Codex and send it the line on the download page. It downloads, installs, and checks everything, and tells you when it needs you.
  • By hand: run curl -fsSL https://lijunhua941-boop.github.io/kitestring-site/install.sh | bash in Terminal, or get the DMG from the download page, then follow the app’s Setup Assistant.
  • Cost: Kitestring for Mac is free, and so is the iPhone app’s demo. Connecting to your own Mac requires Kitestring Pro (a yearly subscription or a one-time purchase; no free trial; the app shows the price). A good order: set up the Mac first, wait until the first steps of the Setup Assistant are checked, then buy on your iPhone and scan.
  • Slow or interrupted download: use the command above. It downloads in parts and resumes; if it stops, run the same command again.

What If Setup Gets Stuck on a Step?

The Setup Assistant in Kitestring for Mac has six steps. You can reopen it at any time by choosing “Setup Assistant…” in the menu bar. The app checks each step automatically and marks it complete. If a step is stuck:

  1. Tailscale: If Tailscale isn’t found, install it from the Tailscale website and sign in. Your iPhone needs it too, signed in with the same account.
  2. Remote Login: The Setup Assistant opens Sharing in System Settings; turn on Remote Login. See below.
  3. Install Helper: The helper is installed only in your home folder and doesn’t require an administrator password. The Setup Assistant lists everything it does. If installation fails, send us the “Diagnostics” results.
  4. Claude Code / Codex: To use coding-agent sessions, install at least one of them by following its official instructions. If you only use terminal sessions, you can skip this step (see below). You can sign in later: start the sign-in from your iPhone, and it runs on your Mac.
  5. Allow Common Folders: macOS asks whether the app can access your Documents, Desktop, and Downloads folders; click Allow. See Folder Access.
  6. Pair iPhone: See Pairing Fails.

How Should I Set Up Tailscale?

  • Sign in to the same Tailscale account on your Mac and your iPhone. In the Tailscale app on each device, check that both are on the same network (tailnet), connected, and not expired.
  • Tailscale on your Mac must accept incoming connections, so don’t turn on “Block incoming connections” (Shields Up).
  • If your tailnet uses access controls (ACLs or grants), allow your iPhone to reach TCP port 22 on your Mac.
  • You don’t need Tailscale SSH. Using different exit nodes on the two devices is fine.

How Do I Turn On Remote Login?

Go to System Settings › General › Sharing and turn on Remote Login. Under “Allow access for,” choose “Only these users” and keep only the account that runs Claude Code or Codex.

Kitestring doesn’t change the global sshd configuration, enable root login, or turn off password login. The key created during pairing accepts logins only from Tailscale addresses and can only open managed sessions.

What If Pairing Fails?

  • The iPhone app asks for Kitestring Pro: connecting to your own Mac requires a purchase (or Restore Purchases) first. The code may have expired by the time you finish, so click “Pair iPhone” on the Mac again and scan the new one.
  • The Mac says another pairing is in progress: only one pairing code can be open at a time. Scan the code that’s already open (in Preview or a Terminal window), or close it first (press Control-C in Terminal), then click “Pair iPhone”.
  • Kite Voice says the code isn’t a Kitestring pairing code: that’s a problem in Kite Voice 1.0.0. Update to 1.0.1 or later in the App Store, then scan again.
  • The code is valid for 10 minutes and can be used only once. If it has expired or was already used, click “Pair iPhone” in the Mac menu bar again.
  • The Mac address in the pairing link must be a Tailscale address. If Tailscale isn’t connected on your iPhone, pairing can’t reach your Mac, so turn on Tailscale first.
  • If you open a pairing link from outside the app, the app first shows the Mac’s name, address, and username, and pairs only after you confirm.
  • If the app says the host identity has changed, don’t trust it blindly: someone may be impersonating your Mac, or the Mac may have been reinstalled or given a new host key. Once you’re sure it’s your Mac, tap “Re-verify Host Identity” in the app’s settings, or pair again.
  • The banner at the top of the app shows where the problem is: Tailscale on your iPhone, the Mac asleep or offline, Remote Login turned off, the helper missing, or the session service not running. Tap “Details” to see the original error.

Why Is a Session Stuck Starting While My Mac Asks for Access to Documents or Desktop?

The session service doesn’t have access to that folder yet, and macOS is waiting for your answer. Click Allow on your Mac. If you clicked Don’t Allow earlier, open System Settings › Privacy & Security › Files and Folders, turn on access to that folder, and then choose “Stop Service” and then “Start Service” in the menu bar. “Diagnostics” in the menu bar shows which folder is blocked.

Why Does Claude Code Say I’m Not Signed In?

If you’re signed in on your Mac but Claude Code says you aren’t in a session, the session service needs to start inside your signed-in desktop session to access the sign-in credentials stored in the login keychain. A service started over SSH can’t read them. Close all sessions, then choose “Stop Service” and then “Start Service” in the Mac menu bar. We never read or copy your credentials, and we never unlock the keychain for you.

Does My Mac Need to Stay On?

Keep your Mac powered on, connected to the network, and awake, with your account signed in. The screen can be locked or the display turned off, but once your Mac goes to sleep, it can’t be reached. Kitestring doesn’t change your power settings; check them under Battery or Energy in System Settings. After your Mac restarts or you log out, the old session processes no longer exist.

Why Does the App Say “No Sessions Yet”?

Your iPhone is connected to your Mac, but there are no managed sessions on it yet. Tap “New Session” below the session list and choose Claude Code, Codex, or Terminal. The session starts in your Mac’s home folder, or you can choose a recent folder. Sessions created on your Mac with Kitestring also appear in the list. “No sessions” in the Sessions section of the Mac menu bar means the same thing.

Why Does the Mac Menu Bar Say “No Paired Devices”?

No iPhone has been paired with this Mac yet, or every paired iPhone has been revoked. Choose “Pair iPhone…” in the menu bar and scan the code with the iPhone app (see Pairing Fails). If your iPhone’s pairing was revoked, the app can no longer connect to this Mac; scan a new code to pair again.

What If Claude Code or Codex Isn’t Installed?

You can still use the app: a Terminal session started from your iPhone is a regular shell on your Mac. To use coding-agent sessions, install Claude Code or Codex on this Mac by following its official instructions (step 4 of the Setup Assistant checks for them and links to them). Then start that type of session on your iPhone. If you start one before installing it, the app tells you that the program wasn’t found on this Mac.

What Should I Do If I Lose My iPhone?

In the Mac menu bar, revoke the iPhone under “Paired Devices.” Keep the app’s Face ID or passcode lock turned on: Claude Code and Codex run in your sessions with your macOS account’s permissions, so anyone with your unlocked iPhone and the app can give them instructions.

How Do I Uninstall?

  1. Choose “Uninstall” in the Mac menu bar. If any sessions are still running, they’re listed first so you can confirm.
  2. Uninstalling revokes every iPhone key (backing up authorized_keys before changing it) and removes the login item and the installed files. The session state folder is retained so it can be restored if you reinstall. Claude Code and Codex credentials, your project code, and your other tmux sessions aren’t touched.
  3. Drag Kitestring for Mac to the Trash.
  4. Delete the app from your iPhone. Tailscale and Remote Login keep your own settings; installation didn’t change them.

How Do I Report a Problem?

  • In the iPhone app, go to Settings › Feedback & Diagnostics. By default, feedback goes to your own Mac; read it under “Inbox & Feedback” in the Mac menu bar.
  • To contact us, email lijunhua941@gmail.com with the app version, the macOS version, and the “Diagnostics” results from the menu bar. Please don’t send session content, keys, or credentials.

¿Por dónde empiezo y cuánto cuesta?

  • Lo más fácil: en el Mac al que quieres conectarte, abre Claude Code o Codex y envíale la línea de la página de descarga. Se encarga de descargar, instalar y comprobarlo todo, y te avisa cuando te necesita.

Un buen orden: configura primero el Mac, espera a que los primeros pasos del Asistente de configuración estén marcados y después compra en tu iPhone y escanea.
  • Descarga lenta o interrumpida: usa el comando de arriba. Descarga por partes y reanuda; si se corta, ejecuta el mismo comando otra vez.

¿Qué hago si la configuración no avanza en un paso?

El Asistente de configuración de Kitestring para Mac tiene seis pasos. Puedes volver a abrirlo cuando quieras con «Asistente de configuración…» en la barra de menús. La app comprueba cada paso automáticamente y lo marca como completado. Si un paso no avanza:

  1. Tailscale: si no se encuentra, instálalo desde el sitio web de Tailscale e inicia sesión. Tu iPhone también lo necesita, con la misma cuenta.
  2. Sesión remota: el Asistente de configuración abre Compartir en Ajustes del Sistema; activa Sesión remota. Consulta más abajo.
  3. Instalar el asistente: el asistente del Mac se instala solo en tu carpeta de inicio y no pide contraseña de administrador. El Asistente de configuración muestra todo lo que hace. Si la instalación falla, envíanos el resultado de «Diagnóstico».
  4. Claude Code / Codex: para usar sesiones de agentes de programación, instala al menos uno siguiendo sus instrucciones oficiales. Si solo usas sesiones de terminal, puedes omitir este paso (consulta más abajo). Puedes iniciar sesión más tarde: lo inicias desde tu iPhone y se ejecuta en tu Mac.
  5. Permitir las carpetas habituales: macOS pregunta si la app puede acceder a tus carpetas Documentos, Escritorio y Descargas; haz clic en Permitir. Consulta Acceso a carpetas.
  6. Vincular iPhone: consulta Falla la vinculación.

¿Cómo configuro Tailscale?

  • Inicia sesión en la misma cuenta de Tailscale en tu Mac y en tu iPhone. En la app de Tailscale de cada dispositivo, comprueba que ambos estén en la misma red (tailnet), conectados y sin caducar.
  • Tailscale en tu Mac debe aceptar conexiones entrantes, así que no actives «Bloquear conexiones entrantes» (Block incoming connections / Shields Up).
  • Si tu tailnet usa controles de acceso (ACL o grants), permite que tu iPhone se conecte al puerto TCP 22 de tu Mac.
  • No necesitas Tailscale SSH. Usar nodos de salida (exit nodes) distintos en los dos dispositivos no es un problema.

¿Cómo activo Sesión remota?

Ve a Ajustes del Sistema › General › Compartir y activa Sesión remota. En «Permitir acceso a», elige «Solo estos usuarios» y deja solo la cuenta que ejecuta Claude Code o Codex.

Kitestring no cambia la configuración global de sshd, no habilita el inicio de sesión como root ni desactiva el inicio de sesión con contraseña. La clave creada durante la vinculación solo acepta conexiones desde direcciones de Tailscale y solo puede abrir sesiones gestionadas.

¿Qué hago si falla la vinculación?

  • La app del iPhone pide Kitestring Pro: para conectarte a tu propio Mac primero hay que comprar (o restaurar las compras). Puede que el código haya caducado cuando termines, así que vuelve a hacer clic en «Vincular iPhone» en el Mac y escanea el nuevo.
  • El Mac dice que hay otra vinculación en curso: solo puede haber un código de vinculación abierto a la vez. Escanea el código que ya está abierto (en Vista Previa o en una ventana de Terminal), o ciérralo primero (pulsa Control-C en Terminal) y después haz clic en «Vincular iPhone».
  • Kite Voice dice que el código no es un código de vinculación de Kitestring: es un problema de Kite Voice 1.0.0. Actualiza a la versión 1.0.1 o posterior en el App Store y vuelve a escanear.
  • El código es válido durante 10 minutos y solo se puede usar una vez. Si caducó o ya se usó, vuelve a hacer clic en «Vincular iPhone» en la barra de menús del Mac.
  • La dirección del Mac en el enlace de vinculación debe ser una dirección de Tailscale. Si Tailscale no está conectado en tu iPhone, la vinculación no puede llegar a tu Mac, así que primero activa Tailscale.
  • Si abres un enlace de vinculación desde fuera de la app, la app primero muestra el nombre, la dirección y el nombre de usuario del Mac, y solo lo vincula cuando lo confirmas.
  • Si la app avisa que la identidad del host cambió, no confíes sin verificar: alguien podría estar suplantando a tu Mac, o quizá el Mac se reinstaló o recibió una clave de host nueva. Cuando estés seguro de que es tu Mac, toca «Volver a verificar la identidad del host» en los ajustes de la app o vuelve a vincularlo.
  • El aviso en la parte superior de la app indica dónde está el problema: Tailscale en tu iPhone, el Mac en reposo o sin conexión, Sesión remota desactivada, falta el asistente del Mac o el servicio de sesiones no está en ejecución. Toca «Detalles» para ver el error original.

¿Por qué una sesión no termina de iniciar mientras el Mac pide acceso a Documentos o Escritorio?

El servicio de sesiones aún no tiene acceso a esa carpeta y macOS está esperando tu respuesta. Haz clic en Permitir en tu Mac. Si antes hiciste clic en No permitir, abre Ajustes del Sistema › Privacidad y seguridad › Archivos y carpetas, activa el acceso a esa carpeta y luego elige «Detener servicio» y después «Iniciar servicio» en la barra de menús. «Diagnóstico» en la barra de menús muestra qué carpeta está bloqueada.

¿Por qué Claude Code dice que no iniciaste sesión?

Si iniciaste sesión en tu Mac pero Claude Code dice lo contrario en una sesión, es porque el servicio de sesiones tiene que iniciarse dentro de tu sesión de escritorio para acceder a las credenciales de inicio de sesión guardadas en el llavero de inicio de sesión. Un servicio iniciado por SSH no puede leerlas. Cierra todas las sesiones y luego elige «Detener servicio» y después «Iniciar servicio» en la barra de menús del Mac. Nunca leemos ni copiamos tus credenciales, ni desbloqueamos el llavero por ti.

¿Mi Mac tiene que estar siempre encendido?

Mantén tu Mac encendido, conectado a la red y activo, con tu cuenta iniciada. La pantalla puede estar bloqueada o apagada, pero cuando el Mac entra en reposo ya no se puede acceder a él. Kitestring no cambia tus ajustes de energía; revísalos en Batería o Energía, en Ajustes del Sistema. Cuando el Mac se reinicia o cierras sesión, los procesos de las sesiones anteriores dejan de existir.

¿Por qué la app dice «Aún no hay sesiones»?

Tu iPhone está conectado a tu Mac, pero todavía no hay sesiones gestionadas en él. Toca «Nueva sesión» debajo de la lista de sesiones y elige Claude Code, Codex o Terminal. La sesión se abre en la carpeta de inicio del Mac, o puedes elegir una carpeta reciente. Las sesiones creadas en el Mac con Kitestring también aparecen en la lista. «No hay sesiones» en la sección Sesiones de la barra de menús del Mac significa lo mismo.

¿Por qué la barra de menús del Mac dice «No hay dispositivos vinculados»?

Todavía no se vinculó ningún iPhone con este Mac, o se revocaron todos los iPhone vinculados. Elige «Vincular iPhone…» en la barra de menús y escanea el código con la app del iPhone (consulta Falla la vinculación). Si se revocó la vinculación de tu iPhone, la app ya no puede conectarse a este Mac; escanea un código nuevo para volver a vincularlo.

¿Qué hago si no tengo Claude Code ni Codex instalados?

Puedes usar la app igualmente: una sesión de Terminal iniciada desde tu iPhone es una shell normal en tu Mac. Para usar sesiones de agentes de programación, instala Claude Code o Codex en este Mac siguiendo sus instrucciones oficiales (el paso 4 del Asistente de configuración los detecta y te da los enlaces). Luego inicia ese tipo de sesión en tu iPhone. Si la inicias antes de instalarlo, la app te avisa que no encontró el programa en este Mac.

¿Qué hago si pierdo mi iPhone?

En la barra de menús del Mac, revoca el iPhone en «Dispositivos vinculados». Mantén activado el bloqueo con Face ID o código de la app: Claude Code y Codex se ejecutan en tus sesiones con los permisos de tu cuenta de macOS, así que cualquier persona que tenga tu iPhone desbloqueado y la app puede darles instrucciones.

¿Cómo desinstalo la app?

  1. Elige «Desinstalar» en la barra de menús del Mac. Si todavía hay sesiones en ejecución, primero se muestran para que lo confirmes.
  2. Al desinstalar, se revocan todas las claves de iPhone (se hace una copia de authorized_keys antes de modificarlo) y se eliminan el elemento de inicio y los archivos instalados. La carpeta de estado de las sesiones se conserva para poder restaurarla si vuelves a instalar la app. No se tocan las credenciales de Claude Code ni de Codex, el código de tus proyectos ni tus otras sesiones de tmux.
  3. Arrastra Kitestring para Mac a la Papelera.
  4. Elimina la app de tu iPhone. Tailscale y Sesión remota conservan tu configuración; la instalación no los modificó.

¿Cómo reporto un problema?

  • En la app del iPhone, ve a Ajustes › Comentarios y diagnóstico. De forma predeterminada, los comentarios se envían a tu propio Mac; léelos en «Bandeja y comentarios» en la barra de menús del Mac.
