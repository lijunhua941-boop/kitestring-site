校验下载的文件（可选）

  1. 核对 SHA-256，输出必须与上表一致： 
    shasum -a 256 <DMG 文件路径>
  2. 核对签名与公证，应看到 accepted 和 source=Notarized Developer ID： 
    spctl -a -t open --context context:primary-signature -v <DMG 文件路径>

    codesign -dv "/Applications/Kitestring.app" 2>&1 | grep Identifier

Let Claude Code or Codex Install It for You (Easiest)

Open Claude Code (or Codex) on this Mac and paste this line. It downloads, installs, checks, and pairs the app for you. You’ll still need to install the iPhone app, sign in to Tailscale, turn on Remote Login, approve macOS permission requests, and scan the QR code; it tells you when.

Run it in Terminal. It downloads the DMG in several parts at once (several times faster on a slow or distant connection), and continues where it stopped if you run the same command again. Download the DMG and Install by Hand

  1. Open the downloaded DMG and drag Kitestring for Mac to the Applications folder.
  2. Open the app and follow the Setup Assistant. The last step shows a pairing code in the window; scan it with the iPhone app.

Verify the Download (Optional)

Run these commands in Terminal. To get the file path, drag the DMG into the Terminal window.

  1. Check the SHA-256. The output must match the table above: 
    shasum -a 256 <path to the DMG>
  2. Check the signature and notarization. You should see accepted and source=Notarized Developer ID: 
    spctl -a -t open --context context:primary-signature -v <path to the DMG>
  3. After installing, check the app’s identifier. You should see Identifier=sh.kitestring.mac: 
    codesign -dv "/Applications/Kitestring.app" 2>&1 | grep Identifier

Updates

The second time you open the app, it asks whether to check for updates automatically. If you agree, it checks regularly, and you can choose “Check for Updates” in the menu bar at any time. Every update is signed by the developer, and the app verifies the signature with its built-in public key before installing. Updating doesn’t interrupt running sessions.
